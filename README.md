# Proverbs ピースソルバー

Steam版パズルゲーム「Proverbs」に登場する、1ピース単位のパズルを自動で解くWebアプリケーションです。ピースの形と数字のヒントを画面で入力して「解く」ボタンを押すと、どのマスを塗ればよいかを計算して表示します。

- 開発者向けの詳細仕様は [docs/Spec.md](docs/Spec.md) を参照してください。

---

## 1. このパズルのルール（はじめての方へ）

- パズルの盤面は「ピース」と呼ばれる、マス目の集まりです。四角形とは限らず、欠けた形をしていることもあります。
- いくつかのマスには **0〜9の数字** が書かれています。
- 数字の意味は「**そのマス自身と、その周囲8マス（合計最大9マス）のうち、ちょうどこの数だけ黒く塗る**」という指示です。
  - 例: 「3」と書かれたマスの周り3×3の範囲では、ちょうど3マスが黒く塗られます。
  - 3×3の範囲がピースの外にはみ出している場合、はみ出した部分は数えません。
  - **数字が書かれたマス自身も「塗る/塗らない」の対象です。**
- すべての数字の指示に合うように、各マスを「塗る」か「塗らない」か決めるのがゴールです。

このアプリは、その答えを自動で計算します。

## 2. 動かすまでの準備

このアプリは自分のパソコン上で動かします。準備は最初の1回だけです。

### 2-1. Node.js をインストールする

このアプリを動かすには **Node.js**（ノードジェイエス）というソフトが必要です。

1. https://nodejs.org/ja を開く
2. 「LTS」と書かれた推奨版をダウンロードしてインストール（設定はすべて初期値のままでOK）

インストールできたか確認するには、次の「ターミナル」で `node -v` と入力して Enter を押し、`v22.0.0` のようなバージョン番号が表示されれば成功です。

### 2-2. ターミナル（黒い画面）を開く

コマンドを入力するための画面を開きます。

- **Windows**: スタートメニューで「PowerShell」を検索して開く
- **Mac**: Launchpad から「ターミナル」を検索して開く

### 2-3. このプロジェクトのフォルダに移動する

ターミナルに次のように入力して Enter を押します（`proverbs-solver` フォルダを置いた場所に合わせて変えてください）。

```bash
cd proverbs-solver
```

> `cd` は「フォルダを移動する」コマンドです。フォルダをエクスプローラー/Finderからターミナルにドラッグ＆ドロップすると、場所を手入力せずに済みます。

### 2-4. 必要な部品をインストールする（最初の1回だけ）

```bash
npm install
```

1〜2分ほどで完了します。これはアプリが使う部品を自動でそろえるコマンドで、2回目以降は不要です。

## 3. アプリを起動する・終了する

### 起動

```bash
npm run dev
```

すると、ターミナルに次のような表示が出ます。

```
  ➜  Local:   http://localhost:5173/
```

この **http://localhost:5173/ をブラウザ（Chrome / Edge / Firefox）のアドレス欄に入力して開いて**ください。「Proverbs ピースソルバー」の画面が表示されれば起動成功です。

- 2回目以降も、起動は「フォルダに移動（2-3）→ `npm run dev`」だけでOKです。

### 終了

- ブラウザのタブを閉じ、ターミナルで **Ctrl+C** を押すとアプリが停止します。

## 4. まずはサンプルで試してみる（3分チュートリアル）

操作に慣れるため、最初は用意済みのサンプル問題を使うのがおすすめです。

1. 画面右上の「**サンプル読込…**」と書かれたプルダウンをクリック
2. 「**基本（確定ルールだけで解ける）**」を選ぶ
   - Step 1 に5×5のピースが、Step 2 に数字ヒントが自動で入ります
3. 画面下の Step 3 にある青い「**解く**」ボタンをクリック
4. 「解けました（一意解）。」と緑色で表示され、黒く塗るマスが表示されます

これがこのアプリの基本の流れです。他の2つのサンプル（制約伝播が必要な問題／バックトラッキングが必要な問題）も同じ手順で試せます。

## 5. 自分で問題を入力する

画面は上から **Step 1 → Step 2 → Step 3** の3段構成です。上から順に入力していきます。

### Step 1: ピースの形を入力する

ゲーム画面のピースと同じ形を作ります。入力方法は2つあり、**どちらを使っても構いません**（両方は常に連動しています）。

**方法A: マスをクリックする**
- 右側のグリッド（マス目）で、ピースに含まれるマスを左クリックします。クリックするたびに「有効（白）⇔ 無効（グレー）」が切り替わります。

**方法B: テキストで入力する**
- 左側の入力欄に、`#`（ピースのマス）と `.`（ピースの外）で形を1行ずつ書きます。
- 例えば、次のように入力すると「上が1マス欠けた3×3」になります:

```
.##
###
###
```

- 間違った文字を書くと赤字でエラーが出ます。その間は反映されないので、直せばOKです。

**グリッドの大きさを変える**
- 「グリッドサイズ: 幅 × 高さ」の数値を変えると、マス目の枠が広がります（それぞれ1〜20）。
- 小さくした場合、はみ出したマスとそのヒントは自動で消えます。

### Step 2: 数字ヒントを入力する

ゲーム画面のピースに書かれている数字を、同じ位置に写します。

1. 数字を書きたいマスを**左クリック**する（青い枠がついて「選択中」になります）
2. **キーボードの数字キー（0〜9）** を押す
3. 消したいときは、そのマスを**右クリック**するか、選択して **Delete キー**

**入力できない数字について**
- そのマスの3×3範囲にあるピースのマス数より大きい数字は入力できません（例: 角のマスで周囲に4マスしかないのに「9」など）。押した瞬間に「9 は入力できません。…」と警告が出ます。実際のゲームに存在する数字ならこの警告は出ません。入力ミスの可能性が高いので、位置と数字を確認してください。
- あとから形を変えたせいで数字が大きすぎになった場合、そのマスが**赤い枠**で表示されます。赤い枠が残っている間は「解く」を押せないので、数字を直すか消してください。

### Step 3: 解く

1. 青い「**解く**」ボタンをクリック（またはキーボードで **Ctrl+Enter**）
2. 結果が色つきのメッセージで表示されます:

| 表示 | 意味 |
|---|---|
| 🟢 解けました（一意解） | 答えは1通りに決まりました。表示されたとおりに塗ればOKです |
| 🟡 複数の解があります | 答えが2通り以上あります（そのうち1つを表示）。入力し忘れたヒントがないか確認してください |
| 🔴 解が存在しません | どう塗っても数字と矛盾します。「ヒント (x, y) で矛盾」と出た場合、そのマスが赤枠になるので、その周辺の入力ミスを探してください |

> 形やヒントを変更すると、表示中の答えは自動で消えます。もう一度「解く」を押してください。

## 6. 答えの見かた

### グリッド表示

| 見た目 | 意味 |
|---|---|
| 黒いマス | **塗る** |
| 白いマス に薄い × | 塗らない |
| 黒いマス に白い数字 | 数字マス自身も**塗る** |
| 白いマス に数字（右上に小さな×） | 数字マスは塗らない |

### テキストアート表示

グリッドの右に、コピーして共有できるテキスト版の答えが表示されます。「コピー」ボタンでクリップボードにコピーできます。

| 記号 | 意味 |
|---|---|
| `■` | 塗る |
| `×` | 塗らない |
| `❶❷…⓿`（黒丸数字） | 数字マスで、塗る |
| `①②…⓪`（白丸数字） | 数字マスで、塗らない |
| `？` / 全角数字 | 未確定（解けなかった場合のみ） |
| 全角スペース | ピースの外 |

> メモ帳などに貼り付けたとき桁がずれる場合は、貼り付け先のフォントを日本語の等幅フォント（例: BIZ UDゴシック、MSゴシック）にしてください。

### PNG画像で保存する

答えの下の「**PNG出力**」ボタンを押すと、答えの盤面が画像ファイルとしてダウンロードされます（タイトルと日時つき）。スクリーンショットを撮らなくても、そのまま共有できます。

## 7. 便利な機能

| 操作 | 方法 |
|---|---|
| 元に戻す（undo） | **Ctrl+Z** または右上の「元に戻す」ボタン |
| やり直す（redo） | **Ctrl+Y** または右上の「やり直す」ボタン |
| 解く | **Ctrl+Enter** または「解く」ボタン |
| 全部消して最初から | 右上の「リセット」ボタン（これも Ctrl+Z で取り消せます） |
| サンプル問題を開く | 右上の「サンプル読込…」プルダウン |

- undo/redo は、マスの編集・数字の入力・サンプル読込・「解く」・リセットまで、直近50手ぶんの操作に効きます。
- 形の入力欄（テキスト）の中で押す Ctrl+Z は、通常の文字入力の取り消しとして動きます。

## 8. うまくいかないとき（Q&A)

**Q. `npm` と打つと「認識されていません」「command not found」と出る**
A. Node.js がインストールされていません。手順 2-1 からやり直してください。インストール直後はターミナルを一度閉じて開き直してください。

**Q. ブラウザで画面が開けない**
A. `npm run dev` を実行したターミナルに表示されている「Local:」のURLを確認してください。他のアプリがポートを使っていると `5174` など別の番号になることがあります。表示されたURLをそのまま開けばOKです。

**Q. 数字キーを押しても入力されない**
A. 先に Step 2 のマスをクリックして、青い枠（選択中）になっているか確認してください。テンキーでも入力できます。

**Q. 「解く」ボタンが押せない（薄いまま）**
A. ボタンの横に理由が表示されます。「先に形状とヒントを入力してください」→ Step 1 が未入力です。「無効なヒント（赤枠）を修正してください」→ Step 2 の赤枠のマスの数字を直すか削除してください。

**Q. 「複数の解があります」と出る**
A. アプリの故障ではありません。入力したヒントだけでは答えが1通りに決まらない状態です。ゲーム画面のヒントをすべて入力できているか確認してください。

**Q. 「解が存在しません」と出る**
A. どこかの入力がゲーム画面と食い違っています。赤枠で示されたマスの周辺から、形・数字・位置を見直してください。

**Q. アプリを終了したい／再起動したい**
A. ターミナルで Ctrl+C を押すと止まります。再開は `npm run dev` だけです。

## 9. 上級者・開発者向け

### コマンド一覧

```bash
npm run dev    # 開発サーバーを起動
npm test       # ユニットテスト（Vitest、63件）
npm run build  # 型チェック + プロダクションビルド
npm run cli -- <problem.json>  # ソルバーをCLIで実行
```

### CLI と問題JSONの形式

```bash
npm run cli -- src/presets/backtrack.json
npm run cli -- <problem.json> --no-propagation   # 制約伝播を無効化（検証用）
```

問題JSONの形式（`src/presets/` と `tests/fixtures/` に実例があります）:

```json
{
  "id": "example",
  "name": "サンプル問題",
  "shape": ["###", "#.#"],
  "clues": { "1,0": 3 }
}
```

- `shape`: `#` = 有効セル、`.` = ピース外の行の配列
- `clues`: `"x,y"`（左上が `0,0`）→ ヒント値

### ソルバーの仕組み

1. **確定ルール**: 各ヒントの塗り数の過不足から確定できるセルを埋める
2. **制約伝播（サブセットルール）**: 重なり合うヒントの差分から確定する（枝刈り最適化。正しさは 1+3 で担保）
3. **バックトラッキング**: 仮定を置いた深さ優先探索。複数解検出のため2つ目の解まで探索する

探索順序は決定的で、同一入力には常に同一の結果を返します。詳細は [docs/Spec.md](docs/Spec.md) の6章を参照してください。

### 技術スタックと構成

- Vite + React + TypeScript + Tailwind CSS v4 + Vitest
- 主要ディレクトリ:
  - `src/solver/` — ソルバー本体（UI非依存）
  - `src/state/` — reducer と undo/redo 履歴管理
  - `src/components/` — UIコンポーネント
  - `src/presets/` — サンプル問題（UIプリセット兼テストデータ）
  - `tests/` — ユニットテスト
